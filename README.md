## 画面与交互设计

- **首页封面与目录**：整屏封面照片，竖排标题与手风琴式目录压在图上；点开一卷时在下方展开缩略图条并切换封面背景与页面底色。背景图按**当前浏览器窗口宽高比**自动匹配该卷的横图或竖图；若无匹配方向（如横屏窗口打开仅含竖图的卷），则自动将竖图完整居右、左侧以图片左边缘颜色无缝渐变延伸（竖屏无竖图时对称居顶并向下延伸）。
- **统一粘性堆叠画册**：每一卷采用「封面 → 简介 → 统一粘性堆叠卡片流（`.plates`）→ 卷尾跋文卡」结构。横幅与竖幅共用同一堆叠容器，滑到视口中心时稳稳驻留，下一张带微倾角度覆盖其上；被压两层以上的旧卡片自动隐藏并释放 GPU 图层，长卷（如 46 张）快速滑动也不会内存暴涨。
- **封面过渡与卷尾跋文卡**：封面滚出时平滑叠加预烘焙模糊层（`blur-NN.webp`）并淡出标题；卷尾跋文卡在手机端呈 `9:16` 竖卡、桌面端呈 `16:9` 宽屏双栏，配朱红印章与上下卷快捷导航。
- **幻灯片透光与预烘焙光晕**：`tools/light.py` 在 OKLab 色彩空间为每张照片计算低饱和深色底纸（写入 `tools/light.json`），并离线生成四周洇开的无损光晕图 `glow-NN.webp` 与模糊层 `blur-NN.webp`；纸面叠一层静态细颗粒 `images/grain.webp` 消除暗色渐变色带。滚动时零实时滤镜计算。
- **背景插画视差层**：`decor.js` 为各卷定制专属 SVG 插画（金步摇、拍立得、青花碎瓷、侦探物件、小熊、山茶、猫咪、蓝宝石、散景光斑等），按页面确定性排布在留白处并避让图片与文字，分 4 个景深层在统一 rAF 循环中平滑移动。
- **看图体验与长截图兼容**：
  - 先加载 `900px` 缩略图，页面静止约 `0.26s` 后（桌面端）再后台解码替换为 `2400px` 原图；点击图片打开原生 `<dialog>` 大图灯箱，支持键盘与移动端手势切图。
  - 所有几何位置仅在页面尺寸变化时单次批量测量，滚动期只写变换样式，避免 layout thrashing。
  - 长截图或打印时（`@media (max-aspect-ratio: 1/3), print`）自动复位动效与粘性定位并补全原图；网址后加 `?still` 可查看静止版。

## 文件结构

| 文件 / 目录 | 作用 |
|---|---|
| `index.html` | 首页（目录 `@works`、季节 `@season`、统计 `@total`、年份 `@year` 由构建脚本自动更新） |
| `about.html` / `about.css` | 个人信息名片页（点击全站任意朱红印章 `.seal` 进入） |
| `series/*.html` | 各卷独立页面，**由 `tools/build-series.mjs` 自动生成，勿手改** |
| `404.html` | 深色极简 404 页 |
| `base.css` | 共用基础：CSS `@layer` 分层、设计 Token、自托管字体、顶栏、朱印、封面、图注、灯箱、动效与长截图规则 |
| `home.css` / `book.css` | 首页样式 / 内页统一堆叠流、卷尾跋文卡与特色背景肌理 |
| `flow.js` | 核心滚动引擎：卡片粘性堆叠与微倾、深埋卡片释放、图注/故事进度、封面模糊淡化、整页透光渐变、空闲原图升级 |
| `decor.js` | 背景插画库与 4 层景深视差引擎 |
| `dir.js` | 首页目录展开、缩略图按需加载重试、桌面横图/手机竖图自适应切背景 |
| `text.js` | 文字动效：`ink` 墨晕 · `rise` 逐字浮现 · `decode` 解码 · `tale` 随滚动展开 |
| `home.js` / `book.js` | 顶栏显隐与当前张数计数 / 原生大图灯箱 |
| `copy/<slug>.md` | **文案源**：卷名、简介、正文、每张图的标题和故事 |
| `tools/series-data.mjs` | **作品元数据**：顺序、日期、器材、EXIF 参数、裁切、封面焦点、`spreads` 顺序、背景 `decor` |
| `tools/light.py` / `tools/light.json` | 离线计算 OKLab 底色、生成 `glow-NN.webp` 与 `blur-NN.webp` |
| `tools/build-series.mjs` / `tools/copy.mjs` | 静态页面生成器、缓存版本号注入（`?v=<sha1>`）、文案长度/缺字检查与校对页 `proof.html` |
| `tools/fonts.py` / `fonts/` | 自托管 Noto Serif SC / Noto Sans SC 可变字体按需子集化（保留竖排特性） |
| `publish.cmd` / `tools/publish.mjs` | 一键发布脚本（自动探测本机代理，无代理时自动直连） |
| `.github/workflows/build.yml` | GitHub Actions 自动生成网页、增量收字、回写仓库并发布 GitHub Pages |

## 写文案 · 校对 · 发布

1. **写文案**：编辑 `copy/<slug>.md`（卷名、简介、正文、单图 `## NN 标题` 与下方故事）。带 `【待审】` 的条目不会在网站显示该标记，但会在校对页高亮提醒。
2. **本地校对**：运行 `node tools/build-series.mjs`，用浏览器打开生成的 `proof.html`（已写入 `.gitignore`，不会发布），检查每张图的排序、字数提示及字体缺字情况。
3. **发布**：
   - **电脑端**：双击 `publish.cmd`（或命令行 `publish.cmd 这次改了什么`），脚本会自动拉取远端改动 → 生成页面 →（若存在 `../_fonts-src`）更新字体 → 提交并推送。
   - **手机 / 网页端**：直接在 GitHub 修改 `copy/*.md` 并提交到 `main`，GitHub Actions 会自动完成生成网页、字体收字、回写提交（`自动生成：网页与字体`）与部署，约 1–2 分钟上线。

## 新增一卷

1. 将照片放入 `images/series/<slug>/`：原图 `01.jpg …`（长边约 2400px，已清除隐私 EXIF）与缩略图 `sm-01.jpg …`（长边约 900px）。
2. 在 `tools/series-data.mjs` 的 `volumes` 顶部照现有格式新增一项（并在 `decor.js` 中复用或新增背景插画 motif）。
3. 新建 `copy/<slug>.md` 填写卷名（及可选的简介、正文、图题、故事）。
4. 运行光照与模糊层预处理（支持单卷增量，依赖 `pillow`、`numpy`、`scipy`）：
   ```bash
   python tools/light.py <slug>
   ```
5. 运行 `node tools/build-series.mjs` 本地预览确认，再执行 `publish.cmd` 发布。
