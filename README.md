# 涂鸦写真帖 — 个人摄影作品站

纯静态网站（HTML + CSS + JS），上传到任意静态托管即可。
首页：封面（整屏照片，竖排标题与「目录」压在图上；点开一卷，内容在这一行下面展开，背后的照片换成这一卷）→ 关于 → 结尾。
每一卷：封面 → 简介 → 一段一段的图 → 卷尾。

现收六卷、78 张（新的在前）：巷子里 · 新一与毛利兰 · 小熊帽 · 冬日的列车 · 五月的树荫 · 咖啡凉了。

## 日式的版面（不靠文字）
- 間：大片留白，图片偏左、偏右、居中交替，不对称
- 竖排卷名压在图片内侧；生成色的纸、墨色的字、一枚朱印
- 每卷的版式（`tools/series-data.mjs` 里的 `spreads`）：
  `single`（align 'l' / 'r' / 'c'）· `scroll` 挂轴（窄而高）· `screen` 屏风（一行等高、窄缝）·
  `pair` 错落的一大一小 · `wide` 宽幅 · `cinema` 宽银幕 · `emaki` 绘卷（宽银幕上下相接）

## 文件
| 文件 | 作用 |
|---|---|
| `index.html` | 首页（封面上的「目录」由脚本生成） |
| `series/*.html` | 每一卷，**由脚本生成，不要手改** |
| `base.css` | 共用：四级文字层级、图片与图注、看图停顿、长截图规则 |
| `home.css` / `book.css` | 首页 / 每一卷的版式 |
| `flow.js` | 图注（压在图上 → 落到图下）、标题浮动 |
| `text.js` | 文字动效：`data-fx="ink"` 墨晕 · `"rise"` 逐字浮现 · `"decode"` 解码 |
| `dir.js` | 首页目录的展开、背景切换 |
| `home.js` | 顶栏（首页与每一卷共用） |
| `book.js` | 点开看大图 |
| `decor.js` | 背景层：从照片里提取的小东西画成插画，飘在留白处（每卷的 `decor` 决定用哪几种） |
| `copy/<卷>.md` | **文字都在这里**：卷名、简介、正文、每张图的标题和故事 |
| `tools/series-data.mjs` | 其余的作品数据：日期、参数、裁切、版式、插画 |
| `tools/build-series.mjs` | 生成器（也生成校对页 `proof.html`，只在本机，不发布） |
| `tools/copy.mjs` | 读写文案、检查长度 |
| `publish.cmd` | 一键发布 |

## 写文案 · 校对 · 发布
**1. 写**：打开 `copy/<卷>.md`（`lane` 巷子里 · `yearend` 新一与毛利兰 · `bear` 小熊帽 · `train` 冬日的列车 · `summer` 五月的树荫 · `cafe` 咖啡凉了）。
```
卷名：巷子里
简介【待审】：二月的一个下午，在巷子里走了三个小时。
正文【待审】：
第一段……

第二段……

## 01 古着店【待审】
![](../images/series/lane/sm-01.jpg)
古着店门口挂满了粉色的花……        ← 故事，可以不写；不写就只显示标题
```
- `## 01` 的 01 是照片文件的编号（`01.jpg`），不是网页上的「图 01」——校对页上两个都有。
- 【待审】= 还是代拟稿。写好或确认过的，把【待审】删掉；网站上不显示它，只在校对页上提醒你。
- 在 GitHub 网页上打开这些 .md，每段文字上面都有那张图的缩略图，手机上也能直接看着图审。

**2. 校对**：运行 `node tools/build-series.mjs`，用浏览器打开 `proof.html`：
每张图（按网页上的顺序）配着标题、故事、字数，标出待审的、可能放不下的
（一排小图里的标题手机上约 6 字；浮在宽幅图上的故事建议 30 字内），以及字体里还没有的字。

**3. 发布**：双击 `publish.cmd`（或 `publish.cmd 这次改了什么`）：取回线上改动 → 生成 → 收进新出现的字 → 提交 → 推送。
约一分钟后线上更新。

**自动生成**：每次推送到 GitHub，`.github/workflows/build.yml` 会自动 生成网页 → 收进新出现的字 → 存回仓库 → 发布。
所以在手机上（GitHub 网页、手机 Claude）**只改 `copy/*.md` 推送就行**，约一两分钟后上线，不用再运行任何命令。
进度在仓库的 Actions 页面：https://github.com/yhun960206-yH/graffiti-photo/actions
（它存回仓库的提交叫「自动生成：网页与字体」；下次电脑上 `publish.cmd` 会自动取回。）

## 加一卷
把照片放进 `images/series/<目录>/01.jpg …`（长边约 2400px，另做 900px 的 `sm-01.jpg …`），
在 `tools/series-data.mjs` 的 `volumes` 里照着现有的加一项，从 `upcoming` 删掉对应的「整理中」；
再新建 `copy/<目录>.md` 写文字（照着现有的写），运行 `python tools/light.py` 和 `publish.cmd`。

## 三层
层次全靠滚动时的速度差：**图片与页面同速**（基准）；**背景插画更快**（在最后，越远越快，滚 100px 约走 120–150px）；
**文字更慢**（在最前：图注约 0.9 倍，正文与故事约 0.85 倍，大标题约 0.78 倍）。每块东西在屏幕正中时回到原位，
所以停下来读时版式不变；长截图里一律原位。插画经过文字背后时会淡到几乎看不见，过去了再回来。

1. **纸（背景）**：每卷从照片里提取几样东西画成插画——巷子里的青花碎瓷片、粉花、咖啡豆；新一与毛利兰的侦探小物件（放大镜、红领结、圆框眼镜、足球、樱花、光尘，原创绘本风，不画人物）；
   小熊帽、羊羔毛卷、旧相机；列车旁的红山茶、叶子、低太阳；树荫里的五叶藤叶、紫叶、叶隙光；咖啡馆的热气、龟背竹、暖灯。
   各有各的动法（飘落、翻转、晃、往上飘、摇、呼吸），只放在空白处，不压图也不压字；位置每次相同；滚动时近大远小。
2. **图**：越接近最佳观看位置越大——偏左的从左下角长出来、偏右的从右下角，里面的照片同时轻轻退远一点。
3. **字**：有故事的图（`series-data.mjs` 里的 `s`），图注落到图下之后，故事一个字一个字展开：
   手机上在图下，电脑上竖排在图旁的留白里；宽幅、宽银幕、绘卷的故事浮在图上。往回滑，字会一个个收回去。
   故事是代拟稿，按你的记忆改写即可。

## 光
把每张照片当成被光照透的幻灯片，光落在背后的纸上（`tools/light.py` 预先算好）：
- **纸的颜色**：取自照片本身的明暗和色调。照片大多偏暗，所以每一卷都是深色纸——照片越暗纸越深，
  色相跟着照片（树荫偏墨绿、列车偏暖棕、巷子偏冷灰），但比照片安静。整页是一条渐变：每张图那一段是它的颜色，
  图与图之间慢慢过渡；顶栏和手机浏览器的顶部颜色跟着当前位置变。文字一律浅色。
- **光晕**：照片四周洇开的一圈光，哪一侧亮、是什么颜色，那一侧的纸就被染上，越远越淡（每张一个十几 KB 的 `glow-NN.webp`，无损、预先平滑放大，暗色上不出现色带）。
- **颗粒**：纸面上铺一层极细的颗粒（不压图、不压字），打散深色渐变在屏幕上的台阶感。
- 都是预先算好的静态画面，滚动时不需要任何计算。加了新照片：`python3 tools/light.py`，再 `node tools/build-series.mjs`。
- 首页：点开目录里的一卷，封面下方的纸换成那一卷的光。

## 流畅优先
滚动的流畅高于一切，图片加载排在它后面：
- 每张图先放 900px 的小图；页面静止约 0.25 秒后，屏幕附近的图才去取 2400px 原图，在一旁解码好再换上，一滚动就暂停。
  长截图、打印时会直接换成全部原图。
- 所有位置只在页面尺寸变化时量一次，滚动时只做算术、只写样式，不让浏览器重新排版。
- 背景插画按远近分成 4 层，滚动时只移动这 4 层；插画的动画只用固定数值，交给 GPU；离屏幕远的停下。
- 图注、故事的进度分级更新；图片只在屏幕附近时才占用 GPU 图层；顶栏去掉了实时模糊。

## 看图的节奏
- **滚动**：完全跟手，不再在每一段停顿或吸附。
- **文字**：主标题墨晕洇开；简介、结尾等句子滚到眼前时逐字浮现；首页目录展开时，简介由乱码解码成原文。
- **图注**：图片从下方进来时，编号和标题压在图上；图片到屏幕正中时，图注已落到图下方、补出日期与拍摄参数，
  故事也已展开完毕——图和字一起在最佳位置，不必等图被裁掉。
- **长截图**：屏幕外的一切都是成品状态；整页截图时所有效果自动复位，所以长截图永远是完整版面。
- 动效始终保留，不受系统「减少动态效果」/ Windows「显示动画」影响；地址后加 `?still` 可看静止版。

## 部署前
- 图片日期、时间、参数取自原片 EXIF；网页用图已去除全部元数据（包括可能的位置信息）
- 每卷的简介是代拟稿，可按你的记忆改写（`tools/series-data.mjs` 的 `lede` 与 `essay`）
- 字体是网站自带的（`fonts/`，只含网站用到的字，宋体约 200KB、黑体约 170KB），不连 Google。
  改了文字、加了新卷之后，在 `node tools/build-series.mjs` 之后再跑一次
  `python tools/fonts.py <原始字体文件夹>`，新出现的字才会被收进去（原始字体的下载地址写在 `tools/fonts.py` 开头）
- 有了域名后，把 `og:image` 改成线上绝对地址；国内服务器需要 ICP 备案号，可加在页脚
