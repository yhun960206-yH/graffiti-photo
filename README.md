# 涂鸦写真帖 — 个人摄影作品站

纯静态网站（HTML + CSS + JS），上传到任意静态托管即可。
首页：封面（竖排标题压在图上，左侧留白处一枚朱印）→ 关于 → 作品（每卷一张图，左右交错）→ 结尾。
每一卷：封面 → 简介 → 一段一段的图 → 卷尾。

现收六卷、78 张（新的在前）：巷子里 · 年末的光 · 小熊帽 · 冬日的列车 · 五月的树荫 · 咖啡凉了。

## 日式的版面（不靠文字）
- 間：大片留白，图片偏左、偏右、居中交替，不对称
- 竖排卷名压在图片内侧；生成色的纸、墨色的字、一枚朱印
- 每卷的版式（`tools/series-data.mjs` 里的 `spreads`）：
  `single`（align 'l' / 'r' / 'c'）· `scroll` 挂轴（窄而高）· `screen` 屏风（一行等高、窄缝）·
  `pair` 错落的一大一小 · `wide` 宽幅 · `cinema` 宽银幕 · `emaki` 绘卷（宽银幕上下相接）

## 文件
| 文件 | 作用 |
|---|---|
| `index.html` | 首页（「作品」部分由脚本生成） |
| `series/*.html` | 每一卷，**由脚本生成，不要手改** |
| `base.css` | 共用：四级文字层级、图片与图注、看图停顿、长截图规则 |
| `home.css` / `book.css` | 首页 / 每一卷的版式 |
| `flow.js` | 图注（压在图上 → 落到图下）、看图停顿、标题浮动 |
| `home.js` | 顶栏（首页与每一卷共用） |
| `book.js` | 点开看大图 |
| `ambient.js` | 每卷背景的淡淡氛围（只在留白处） |
| `tools/series-data.mjs` | **所有作品内容都在这里** |
| `tools/build-series.mjs` | 生成器 |

## 改内容 / 加一卷
改 `tools/series-data.mjs`，然后运行：
```
node tools/build-series.mjs
```
新的一卷：把照片放进 `images/series/<目录>/01.jpg …`（长边约 2400px，另做 900px 的 `sm-01.jpg …`），
在 `volumes` 里照着现有两卷加一项，并从 `upcoming` 删掉对应的「整理中」。

## 看图的节奏
- **停顿**：每一段（`data-rest`）都有一个最佳观看位置。用滚轮或触控板经过时，页面会在那里卡一下——
  滑到位、停约三分之一秒，再继续；手指滑动时由浏览器吸附。只响应你自己的操作，截图工具的程序滚动不受影响。
- **图注**：图片来到最佳位置时，编号和标题压在图上；继续往下滑，图注落到图下方，并补出日期与拍摄参数。
- **长截图**：屏幕外的一切都是成品状态；整页截图时所有效果自动复位，所以长截图永远是完整版面。
- 系统开启「减少动态效果」时全部静止；`?motion` 可强制预览。

## 以后加联系方式
在 `index.html` 的结尾部分（`.close`）加一行即可，例如：
```html
<p class="t-note">邮箱　you@example.com</p>
```

## 部署前
- 图片日期、时间、参数取自原片 EXIF；网页用图已去除全部元数据（包括可能的位置信息）
- 每卷的简介是代拟稿，可按你的记忆改写（`tools/series-data.mjs` 的 `lede` 与 `essay`）
- 字体走 Google Fonts，国内建议自托管；失败时回退系统宋体
- 有了域名后，把 `og:image` 改成线上绝对地址；国内服务器需要 ICP 备案号，可加在页脚
